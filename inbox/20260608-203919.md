# 带 Tajik 过滤 VCF 四亚群遗传多样性指标计算与可视化

## 项目与目的
- 项目路径：/data1/gh/sy/vcf
- 目的：使用当前默认带 Tajik 过滤 VCF，按 TAJ/XJ/GNN/NM 四亚群计算并可视化 pi、FST、Ho、He、Tajima's D、ROH。

## 输入
- VCF：/data1/gh/sy/vcf/admixture_pca_tree_tajik/tajik.maf0.05.minAllele2.maxAllele2.vcf.gz
- 分组表：/data1/gh/sy/vcf/分组样品/current_201_subgroup_assignments.tsv
- 输出目录：/data1/gh/sy/vcf/genetic_diversity_tajik_k4
- 样本数：TAJ=10，XJ=57，GNN=79，NM=55；全部与 VCF 匹配，missing_in_vcf=0。

## 脚本
- 计算脚本：/data1/gh/sy/vcf/scripts/run_genetic_diversity_tajik_k4.sh
- 作图脚本：/data1/gh/sy/vcf/scripts/plot_genetic_diversity_tajik_k4.R

## 参数
- pi：vcftools --window-pi 100000 --window-pi-step 10000
- Tajima's D：vcftools --TajimaD 100000
- FST：vcftools --weir-fst-pop pairwise --fst-window-size 100000 --fst-window-step 10000
- Ho/He：vcftools --het；Ho=1-O(HOM)/N_SITES，He=1-E(HOM)/N_SITES
- ROH：plink --homozyg --homozyg-window-snp 50 --homozyg-window-het 1 --homozyg-window-missing 5 --homozyg-snp 50 --homozyg-kb 100 --homozyg-density 50 --homozyg-gap 1000
- PLINK VCF 转换：--allow-extra-chr --double-id --vcf-half-call missing

## 主要问题与修复
- PLINK 首次转换报错：Multiple instances of '_' in sample ID。
- 原因：PLINK 默认将 `_` 当作 FID/IID 分隔符，当前样本名含多个 `_`。
- 修复：加入 --double-id，保持完整 sample ID 作为 FID/IID。
- R 汇总初版将无表头 sample_subgroup.tsv 当作有表头读取，导致 TAJ 的 ROH 样本数少 1；已修复为 header=FALSE，并重新生成汇总与图。
