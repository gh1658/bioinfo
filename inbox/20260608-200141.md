# LD decay 更正重跑：带 Tajik 版本 VCF

## 背景
用户指出前一次 LD decay 试跑误用了不带 Tajik 的 191 样本 VCF；项目后续所有分析默认应使用带 Tajik 的 VCF。本记录为更正后的带 Tajik 版本结果，前一次不带 Tajik 的 LD 试跑不作为后续默认依据。

## 输入数据
- 带 Tajik 未过滤 VCF：/data1/gh/sy/vcf/glnexus_merge/merge_with_1to10_exclude_13_14_94.by_chr.vcf.gz
  - 样本数：202
  - 全文件位点数：194,154,942
- 带 Tajik 过滤后常用 VCF：/data1/gh/sy/vcf/admixture_pca_tree_tajik/tajik.maf0.05.minAllele2.maxAllele2.vcf.gz
  - 样本数：201
  - 全文件 SNP 数：1,034,322

## 处理策略
- 未过滤大 VCF 含复杂 indel/多等位/半缺失 GT，bcftools 直接 SNP 过滤会在部分位点报 `Invalid character '0' in 'GT' FORMAT field`。
- 为避免复杂位点影响 PopLDdecay，未过滤输入用 `tabix -h` 抽区间文本，再用 awk 仅保留 REF/ALT 均为单碱基且 ALT 不含逗号的双等位 SNP。
- PopLDdecay 参数：`-MaxDist 100` 用于 100kb 同区间对照；过滤后 VCF 另用 `-MaxDist 300` 跑 10Mb 稳定参考。
- PopLDdecay 内部默认过滤：MAF=0.005，Miss=0.25，Het=0.88。

## 关键命令
```bash
tabix -h glnexus_merge/merge_with_1to10_exclude_13_14_94.by_chr.vcf.gz Chromosome_1:10000000-10100000 \
  | awk 'BEGIN{FS=OFS="\t"} /^#/ {print; next} length($4)==1 && length($5)==1 && $5 !~ /,/ {print}' \
  | bgzip -c > ld_decay_tajik/input/tajik_unfiltered.chr1_10_10p1Mb.snps.vcf.gz

tools/PopLDdecay/bin/PopLDdecay -InVCF ld_decay_tajik/input/tajik_unfiltered.chr1_10_10p1Mb.snps.vcf.gz \
  -OutStat ld_decay_tajik/stat/tajik_unfiltered.chr1_10_10p1Mb.MaxDist100.stat.gz -MaxDist 100

tools/PopLDdecay/bin/PopLDdecay -InVCF ld_decay_tajik/input/tajik_maf005.chr1_10_20Mb.vcf.gz \
  -OutStat ld_decay_tajik/stat/tajik_maf005.chr1_10_20Mb.MaxDist300.stat.gz -MaxDist 300
```

## 结果
- 同区间 100kb 未过滤：抽取 16,386 个 SNP，PopLDdecay 内部过滤后保留 11,019 个 SNP；1bp Mean r2=0.1334；0-1kb 平均 r2=0.0487；50-100kb 平均 r2=0.0190。
- 同区间 100kb 过滤后：抽取 211 个 SNP，PopLDdecay 内部过滤后保留 180 个 SNP；位点太少，曲线不稳定，只用于确认输入已改为带 Tajik，不建议作为正式 LD 结论。
- 过滤后 10Mb：抽取 11,102 个 SNP，PopLDdecay 内部过滤后保留 9,352 个 SNP；1bp Mean r2=0.5548；0-1kb 平均 r2=0.3304；1-5kb=0.2616；5-10kb=0.2383；10-50kb=0.2028；50-100kb=0.1873；100-300kb=0.1714。

## 后续默认
- 后续 LD、多样性、FST、ROH 等分析默认使用带 Tajik 的版本；除非用户明确要求，不再使用 `merge_without_1to10...` 作为默认输入。
